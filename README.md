# MSc Bioinformatics — Projects

This repository contains projects completed during my **MSc in Bioinformatics at Lund University**.

## Project Naming Convention

Projects follow this format:

<div style="background-color:#e8f4ff; border-left:5px solid #2f81f7; padding:12px 16px; border-radius:6px;">

<strong><code>YYMM_BINP17_Topic_Name</code></strong>

</div>

- `YYMM` — year and month of completion
- `BINP17` — course code
- `Topic_Name` — project topic
